Measurement notes

WebGPU run wall time includes CPU dispatch, input upload, GPU execution, output readback and synchronization. It excludes model load, two warmup runs and rendering. GPU kernel-only time is not measured. Small models may be dominated by overhead.

Tensor storage estimates exclude other activations, copies, runtime workspaces and allocator overhead. Browser/device peak GPU memory is not measured.
